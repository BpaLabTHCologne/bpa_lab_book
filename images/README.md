# Images

This folder holds the diagrams and graphics used in the book. Please copy the following files from <https://github.com/BpaLabTHCologne/bpa_lab_docs> into this folder.

## Required image files

| File name here | Source in `bpa_lab_docs` |
|---|---|
| `Conceptional_Architecture.png` | `Updated_graphics/Conceptional_Architecture.png` |
| `BPALab_Simplified_Arch_240924.png` | `BPALab_Simplified_Arch_240924.png` (root) |
| `process_landscape.png` | `Updated_graphics/process_landscape.png` |
| `data_overview.png` | `Updated_graphics/data_overview.png` |
| `mysql_data_model.png` | `Updated_graphics/mysql_data_model.png` |
| `c4-contextDiagram.drawio.png` | `C4architecture/c4-contextDiagram.drawio.png` |
| `C4_System_Architecture.png` | `Updated_graphics/C4_System_Architecture.png` |
| `logo.svg` *(optional)* | favicon — a simple BPA-Lab logo, used in the browser tab |
| `cover.png` *(optional)* | ePub cover image |

## Quick download via the command line

```bash
cd images

# Repeat for each file as needed:
curl -L -o Conceptional_Architecture.png \
  https://raw.githubusercontent.com/BpaLabTHCologne/bpa_lab_docs/main/Updated_graphics/Conceptional_Architecture.png

curl -L -o BPALab_Simplified_Arch_240924.png \
  https://raw.githubusercontent.com/BpaLabTHCologne/bpa_lab_docs/main/BPALab_Simplified_Arch_240924.png

curl -L -o process_landscape.png \
  https://raw.githubusercontent.com/BpaLabTHCologne/bpa_lab_docs/main/Updated_graphics/process_landscape.png

curl -L -o data_overview.png \
  https://raw.githubusercontent.com/BpaLabTHCologne/bpa_lab_docs/main/Updated_graphics/data_overview.png

curl -L -o mysql_data_model.png \
  https://raw.githubusercontent.com/BpaLabTHCologne/bpa_lab_docs/main/Updated_graphics/mysql_data_model.png

curl -L -o c4-contextDiagram.drawio.png \
  https://raw.githubusercontent.com/BpaLabTHCologne/bpa_lab_docs/main/C4architecture/c4-contextDiagram.drawio.png

curl -L -o C4_System_Architecture.png \
  https://raw.githubusercontent.com/BpaLabTHCologne/bpa_lab_docs/main/Updated_graphics/C4_System_Architecture.png
```

Alternatively, download the files manually through the GitHub web interface and drop them here.
